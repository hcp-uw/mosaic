Mosaic Command Line Interface — Distributed Storage Network

Account:
  login <key>                             Log in with your key.
  login status                            Show current login status.
  logout account                          Log out and remove session credentials.

Network:
  join network                            Join the storage network.
  leave network                           Disconnect from the network.
  status network                          Show connection state, role (leader/member), peers, and storage.
  peers network                           List peers currently connected to the network.

Node & Account:
  status node <node_id>                   View information about a specific node.
  status account                          View overall account status and all connected nodes.

Storage:
  set storage <amount>                    Set the total storage to share with the network.
  empty storage                           Delete all your files from the network (irreversible).

Files:
  list file                               List files with a local stub or cached copy on this machine.
  list manifest                           List all files in your network manifest (cross-machine view).
  upload file <path>                      Upload a file to the network. Shows progress for large files.
  upload folder <path>                    Upload a folder to the network.
  download file <name>                    Download a file from the network to ~/Mosaic/.
  download folder <name>                  Download a folder from the network.
  info file <name>                        Display metadata for a specific file.
  info folder <name>                      Display metadata for a specific folder.
  delete file <name>                      Delete a file from the network, manifest, and all shard holders.
  delete file -s <name>                   Remove the local stub only (file stays in network manifest).
  delete folder <name>                    Delete a folder from the network.
  rename file <oldname> <newname>         Rename a file on the network.

Debug:
  debug msg "<text>"                      Send a text message to all peers (tests P2P link and session encryption).

Other:
  version                                 Display current Mosaic client version.
  doctor                                  Run connectivity and health self-tests (daemon, keys, STUN, TCP relay, per-peer transport).
  wipe                                    Delete all local state for testing (~/Mosaic/, keys, shards). Prompts for confirmation.
  shutdown                                Stop the daemon and uninstall binaries.
  help                                    Show this help message.
